# Lucid Wiki

A living wiki for tracking and organizing everything in the film series: objects, characters, locations, and events.
Plain Markdown, hosted on GitHub so it can be edited by hand or by AI agents.

## Structure

| Folder | Contents |
|---|---|
| `objects/` | Objects and artifacts, each with a **Rank** (inspired by the SCP Wiki) |
| `characters/` | People and characters, each with a **Level** and **Skills** (inspired by the Lord of Mysteries Wiki) |
| `locations/` | Places and settings |
| `events/` | Key events and timeline entries |
| `templates/` | Copy these to start a new page |

See [`index.md`](index.md) for the page directory and [`AGENTS.md`](AGENTS.md) for editing rules.
